# Redcode standards

Copies of the documents used for [the quirks and conformance report](../Quirks.md). They were
downloaded on 2026-09-27 and are kept here unchanged, so the report can be checked even if the
originals move.

| File | Document | Downloaded from |
| --- | --- | --- |
| `cwg.txt` | Core War Guidelines, D. G. Jones and A. K. Dewdney, March 1984 | https://corewar.co.uk/standards/cwg.txt |
| `icws88.txt` | "Core War '88 - A Proposed Standard", Thomas Gettys, The Core War Newsletter, Summer 1988 (ICWS'88), text with the original two-column layout | https://corewar.co.uk/standards/icws88.txt |
| `redcode88.pdf` | The same '88 proposal, typeset | https://corewar.co.uk/standards/redcode88.pdf |
| `icws94.txt` | "Annotated Draft of the Proposed 1994 Core War Standard", version 3.3, November 1995, base draft by Mark Durham, edited by Damien Doligez | https://corewar.co.uk/standards/icws94.txt |
| `pontello-icws86-guide-it.txt` | "Guida a Core War & Redcode - ICWS-86", Marco Pontello, 1996-2002, in Italian (saved as `corewar.txt` on the site) | https://corewar.co.uk/pontello/corewar.txt |

The index of the standards on that site is https://corewar.co.uk/standards/. It also has two earlier
versions of the '94 draft and `emi94.c`, the instruction executor that goes with it, which the report
doesn't use.

The ICWS'86 standard itself ("Core Wars", May 1986, mainly by Graeme McRae) wasn't found online. The
report takes its '86 statements from the Pontello guide and from the '94 draft, which describes the
'86 instructions in appendix A.2.1.1 and the '86 run-time settings in section 4.3.

The copyright of each document stays with its authors and publishers.
